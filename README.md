# ServerEconomyTracker

ServerEconomyTracker is a Minecraft economy analytics plugin designed to monitor, analyze, and visualize the complete server economy across multiple economy systems and plugins.

The plugin tracks money flow, detects sources and sinks, calculates total server wealth, and provides detailed statistics about player balances and economic activity. It is built for server owners who want deeper insight into how their economy behaves over time.

## Features
- Economy Tracking
- Track total server wealth
- Monitor player balance changes in real time
- Detect money sources and money sinks
- Track economy growth over time
- Store historical economy statistics

## Transaction Analysis
- Detect player-to-player transfers
- Classify transactions into:
  Sources
  Sinks
  Transfers

## Commnads
- /economytracker reload
- /economytracker stats

## Permissions
- economytracker.stats
- economytracker.reload
